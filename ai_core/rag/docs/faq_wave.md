# FAQ Wave — Support Client

## Frais et Tarifs

### Quels sont les frais de transfert Wave ?
Wave pratique des frais de transfert de **1% du montant** pour les envois vers d'autres utilisateurs Wave au Senegal.
Les transferts entre utilisateurs Wave sont gratuits dans certains cas promotionnels.
Pour les transferts vers d'autres operateurs (interoperabilite), des frais supplementaires peuvent s'appliquer.

### Quels sont les frais de retrait chez un agent Wave ?
Le retrait chez un agent Wave est gratuit pour les clients reguliers.
Des frais de 1% peuvent s'appliquer selon le type de compte et la frequence des retraits.

### Y a-t-il des frais pour les paiements marchands ?
Les paiements via QR Code chez les marchands partenaires Wave sont gratuits pour le client.
Le marchand supporte une commission de 0.5% a 1%.

## Limites de Transaction (BCEAO)

### Quelle est la limite journaliere de transfert ?
- Compte non verifie (KYC incomplet) : **100 000 XOF par jour**
- Compte verifie (KYC complet) : **500 000 XOF par jour**
- Compte premium : **1 000 000 XOF par jour**

### Quelle est la limite mensuelle ?
- Compte standard verifie : **2 000 000 XOF par mois**
- Compte premium : **5 000 000 XOF par mois**

Ces limites sont fixees par la reglementation BCEAO (Banque Centrale des Etats de l'Afrique de l'Ouest).

### Comment relever mes limites ?
Pour augmenter vos limites, vous devez completer votre verification KYC :
1. Ouvrir l'application Wave
2. Aller dans Profil > Verification d'identite
3. Soumettre votre piece d'identite (CNI, passeport)
4. Attendre la validation (24 a 48 heures)

## Inscription et Compte

### Comment ouvrir un compte Wave ?
1. Telecharger l'application Wave sur Android ou iOS
2. Entrer votre numero de telephone senegalais
3. Scanner votre carte d'identite nationale
4. Prendre un selfie pour la verification biometrique
5. Definir votre PIN a 4 chiffres

### Comment reinitialiser mon PIN ?
1. Sur l'ecran de connexion, appuyer sur "PIN oublie"
2. Entrer votre numero de telephone
3. Recevoir un OTP par SMS
4. Definir un nouveau PIN

### Que faire si mon compte est bloque ?
Le blocage peut survenir apres 3 tentatives de PIN incorrectes.
Contactez le support Wave au **3330** ou via l'application.
Vous devrez verifier votre identite avec un OTP et des questions de securite.

## Transactions

### Que faire si mon transfert n'est pas arrive ?
1. Verifier que le numero du beneficiaire est correct
2. Patienter 5 a 10 minutes (delai reseau normal)
3. Si apres 30 minutes le transfert n'est pas arrive, contacter le support
4. Fournir la reference de la transaction (visible dans l'historique)
Wave garantit le remboursement si le montant a ete debite sans credit chez le beneficiaire.

### Que faire si j'ai envoye vers le mauvais numero ?
Wave ne peut pas annuler un transfert complete vers un beneficiaire existant.
Vous pouvez contacter le support pour tenter une mediation avec le beneficiaire.
Si le numero n'existe pas, le montant est automatiquement rembourse sous 24h.

### Comment retrouver la reference d'une transaction ?
Aller dans l'application Wave > Historique > Selectionner la transaction.
La reference est au format WV-AAAAMMJJ-XXXX.

## Reseau d'Agents

### Comment trouver un agent Wave pres de moi ?
Utiliser la carte dans l'application Wave pour localiser les agents actifs.
Les agents Wave sont identifies par le logo Wave orange.
Vous pouvez filtrer par disponibilite et distance.

### Que faire si l'agent n'a pas de liquide ?
Signaler l'agent via l'application : Agents > Signaler un probleme.
Wave enverra une alerte au superviseur regional.
Utilisez la carte pour trouver un agent alternatif.

### Que faire si l'agent a pris mon argent sans crediter mon compte ?
C'est une situation grave. Actions immediates :
1. Ne pas quitter les lieux si possible
2. Demander le recu de la transaction
3. Contacter le support Wave immediatement au **3330**
4. Wave ouvrira une investigation prioritaire (resolution sous 24-48h)
