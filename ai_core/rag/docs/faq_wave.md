# FAQ Wave Senegal — Support Client

## Frais et Tarifs (mis a jour 2025)

### Quels sont les frais de transfert Wave au Senegal ?
Wave applique les frais suivants pour les transferts entre comptes Wave :
- **Transfert entre comptes Wave : 1% du montant** (ex : 100 FCFA pour 10 000 FCFA)
- **Plafond des frais : 5 000 FCFA** quel que soit le montant envoye
- **Depot (cash-in) : GRATUIT** — deposer de l'argent chez un agent ne coute rien
- **Retrait (cash-out) chez agent : GRATUIT**
- **Paiement marchand via QR Code : GRATUIT** pour le client

Pour les transferts entre compte bancaire et compte Wave, les frais sont plafonnes a 500 FCFA.

### Quels sont les frais pour les transferts internationaux Wave ?
- Transferts vers Cote d'Ivoire, Mali, Burkina Faso : **1% du montant**
- Les frais s'appliquent a l'envoi, le retrait chez le beneficiaire est gratuit

### Y a-t-il des frais pour les paiements marchands ?
Non, les paiements via QR Code chez les marchands partenaires Wave sont **entierement gratuits** 

## Limites de Transaction (BCEAO)

### Quelle est la limite journaliere de transfert ?
- Compte non verifie (KYC incomplet) : **100 000 XOF par jour**
- Compte verifie (KYC complet) : **500 000 XOF par jour**

### Quelle est la limite mensuelle ?
- Compte verifie : **2 000 000 XOF par mois**

Ces limites sont fixees par la BCEAO (Instruction n°008/2022 relative aux services de monnaie electronique).

### Quelle est la limite de solde sur un compte Wave ?
- Compte de base : maximum **200 000 XOF**
- Compte verifie : maximum **2 000 000 XOF**

### Comment relever mes limites ?
Pour augmenter vos limites, completez votre verification KYC :
1. Ouvrir l'application Wave
2. Aller dans Profil > Verification d'identite
3. Soumettre votre CNI (Carte Nationale d'Identite) ou passeport biometrique
4. Prendre un selfie pour la verification biometrique
5. Validation sous 24 a 48 heures

## Inscription et Compte

### Comment ouvrir un compte Wave ?
1. Telecharger l'application Wave sur Android ou iOS
2. Entrer votre numero de telephone senegalais
3. Scanner votre carte d'identite nationale
4. Prendre un selfie pour la verification biometrique
5. Definir votre PIN a 4 chiffres
L'inscription est gratuite et se fait entierement depuis l'application.

### Comment reinitialiser mon PIN ?
1. Sur l'ecran de connexion, appuyer sur "PIN oublie"
2. Entrer votre numero de telephone
3. Recevoir un code OTP par SMS
4. Saisir le code OTP
5. Definir un nouveau PIN a 4 chiffres
Si vous n'avez plus acces a votre numero, rendez-vous dans une agence Wave avec votre CNI.

### Que faire si mon compte est bloque ?
Le blocage survient apres 3 tentatives de PIN incorrectes.
- Contacter Wave au **3330** (gratuit depuis un numero Wave)
- Ou via l'application : Menu > Aide > Contacter le support
- Vous devrez verifier votre identite avec un OTP et des questions de securite
Delai de deblocage : generalement moins de 30 minutes.

## Transactions

### Que faire si mon transfert n'est pas arrive ?
1. Verifier que le numero du beneficiaire est correct dans votre historique
2. Patienter 5 a 10 minutes (delai reseau normal)
3. Verifier que le statut dans votre application est "Complete" ou "En attente"
4. Si apres 30 minutes le transfert reste en attente, contacter le support au **3330**
5. Fournir la reference de la transaction (format WV-AAAAMMJJ-XXXX visible dans l'historique)
Wave garantit le remboursement si le montant a ete debite sans etre credit chez le beneficiaire.

### Que faire si j'ai envoye vers le mauvais numero ?
Wave ne peut pas annuler un transfert qui a ete complete vers un beneficiaire existant.
- Contacter immediatement le support au **3330**
- Wave peut tenter une mediation si le beneficiaire est aussi client Wave
- Si le numero n'existe pas dans le systeme, le montant est automatiquement rembourse sous 24h
- En cas de fraude averee, Wave ouvrira une investigation

### Comment retrouver la reference d'une transaction ?
Dans l'application Wave : Accueil > Selectionner la transaction.
La reference est au format **WV-AAAAMMJJ-XXXX**.

## Reseau d'Agents

### Comment trouver un agent Wave pres de moi ?
- Utiliser la carte dans l'application Wave : Menu > Trouver un agent
- Les agents Wave sont identifies par le logo Wave orange
- Vous pouvez filtrer par disponibilite et distance
- Plus de **100 000 points de service** en zone UEMOA

### Que faire si l'agent n'a pas de liquide (flotte insuffisante) ?
1. Demander a l'agent de signaler sa situation a Wave via son application agent
2. Utiliser la carte dans l'application pour trouver un agent alternatif dans votre zone
3. Signaler l'agent via l'application : Trouver un agent > Signaler un probleme
Wave notifiera le superviseur regional pour reapprovisionner l'agent.

### Que faire si l'agent a pris mon argent sans crediter mon compte ?
Situation grave — procedure d'urgence :
1. Ne pas quitter les lieux si possible, demander à voir la transaction
2. Prendre une photo ou noter le nom et l'ID de l'agent
3. Appeler immediatement le **3330**
4. Wave ouvrira une investigation prioritaire (P1) — resolution sous 24 a 48h
5. Si fraude confirmee, remboursement integral et suspension de l'agent

## Securite

### Comment proteger mon compte Wave ?
- Ne jamais communiquer votre PIN a qui que ce soit — Wave ne vous le demandera JAMAIS
- Activer les notifications de transaction dans l'application
- Ne pas partager votre ecran avec des inconnus
- En cas d'appel suspect demandant votre PIN, raccrocher et appeler le 3330

### Que faire en cas de SIM swap ou de piratage ?
1. **Bloquer immediatement votre compte** : appeler le **3330** et demander le blocage d'urgence
2. Aller dans une agence Wave avec votre CNI originale
3. Porter plainte a la police (requisition necessaire pour l'enquete)
4. Wave remboursera les pertes liees a un SIM swap prouve apres investigation
