# FAQ Mixx by Yas (Axian) — Support Client

## Frais et Tarifs

### Quels sont les frais de transfert Mixx ?
- **Transfert entre comptes Mixx : GRATUIT**
- **Transfert vers autres operateurs : 1% du montant**
- **Depot (cash-in) chez agent : GRATUIT**
- **Retrait (cash-out) chez agent : 1% du montant**
- **Paiement marchand : GRATUIT** pour le client
- **Paiement de factures (SENELEC, SEN'EAU) : GRATUIT**

### Frais avec la carte Mixx Mastercard ?
- Paiement en ligne ou en magasin avec la carte : **GRATUIT**

### Y a-t-il un abonnement mensuel ?
Non, il n'y a pas de frais d'abonnement ou de tenue de compte sur Mixx.

- Compte verifie standard : **500 000 XOF par jour**

### Quelle est la limite mensuelle ?
- Compte verifie : **2 000 000 XOF par mois**

### Quelle est la limite de solde ?
- Compte verifie : maximum **2 000 000 XOF**

## Code USSD

### Comment acceder a Mixx sans smartphone ?
Composez **#150#** depuis votre telephone Yas ou tout telephone compatible.
Menu principal :
1. Kalpae (envoyer de l'argent)
2. Retirer de l'argent
3. Payer une facture
4. Mon solde
5. Mes services Mixx

### Qu'est-ce que Kalpae ?
**Kalpae** est le nom wolof du service de transfert d'argent Mixx by Yas.
"Kalpae" signifie "bourse" ou "portefeuille" en wolof.
C'est le terme utilise dans toutes les communications Mixx pour designer le mobile money.

### Comment envoyer de l'argent via USSD (#150#) ?
1. Composer **#150#**
2. Choisir "1. Kalpae" (envoyer de l'argent)
3. Entrer le numero du beneficiaire
4. Entrer le montant
5. Confirmer avec votre PIN a 4 chiffres

## Carte Mixx Mastercard

### Comment obtenir ma carte Mixx Mastercard ?
1. Avoir un compte Mixx verifie (KYC complet)
2. Faire la demande dans l'application : Menu > Carte > Commander ma carte
3. La carte est disponible en agence Yas sous **5 a 7 jours ouvrables**
4. Activer la carte dans l'application au moment du retrait
La carte est gratuite a l'emission.

### Quelle est la limite d'utilisation de la carte ?
- Paiement en ligne par transaction : **200 000 XOF**
- Paiement en magasin par transaction : **500 000 XOF**
- Retrait DAB par jour : **150 000 XOF**

### Ma carte est bloquee ?
Votre carte se bloque automatiquement apres **3 tentatives de code incorrect**.
Pour debloquage :
- Via l'application Mixx : Menu > Ma Carte > Debloquage
- Contacter le support au **3232**
- En cas de blocage de securite (suspicion fraude), se rendre en agence avec CNI

## Credit Lebalma

### Qu'est-ce que Lebalma ?
Lebalma est le service de microcredit instantane Mixx by Yas.
Il permet d'obtenir un credit entre **1 000 et 50 000 XOF** sans garantie, directement credit sur votre Kalpae.

### Comment obtenir un credit Lebalma ?
1. Avoir un compte Mixx actif depuis **au moins 3 mois**
2. Avoir un historique de transactions regulier
3. Application Mixx : Menu > Services > Lebalma
4. Choisir le montant et la duree de remboursement
5. Accepter les conditions de taux
6. Credit vire instantanement sur votre Kalpae

### Taux d'interet Lebalma ?
Les taux varient selon le profil du client et la duree. Ils sont affiches clairement avant confirmation dans l'application. En cas de difficulte de remboursement, contactez le **3232** avant la date d'echeance.

## Transactions

### Mon transfert Mixx n'est pas arrive ?
1. Verifier l'historique dans l'application (Accueil > Historique)
2. Patienter 10 a 15 minutes (delai normal sur le reseau)
3. Si statut "En attente" depuis plus d'1 heure, contacter le **3232**
4. Fournir la reference de transaction au format **MX-AAAAMMJJ-XXXX**

### Que faire en cas de double debit ?
1. Prendre une capture d'ecran de votre historique montrant le double debit
2. Contacter immediatement le **3232** ou via l'application
3. Le remboursement du doublon est effectue sous **2 heures** si confirme

### Paiement de factures SENELEC ou SEN'EAU ?
Via l'application : Menu > Paiements > Choisir le fournisseur (SENELEC ou SEN'EAU)
Via USSD : **#150#** > "3. Payer une facture"
Le paiement est **gratuit** et pris en compte sous **30 minutes**.

## Securite

### Comment proteger mon compte Mixx ?
- PIN unique et confidentiel — Mixx ne vous le demandera **jamais** par telephone
- Activer la verification biometrique (empreinte digitale ou Face ID si disponible)
- Activer les notifications de transaction dans l'application
- Ne jamais installer d'applications tierces demandant votre acces Mixx

### Que faire si je suspecte une fraude ?
1. **Bloquer immediatement** : Application > Securite > Bloquer mon compte
2. Appeler le **3232** — option "Urgence securite"
3. Se rendre en agence Yas avec votre CNI pour reinitialisation complete
4. Mixx ouvrira une investigation dans les **2 heures**

## Reseau d'Agents

### Trouver un agent Mixx ?
- Application Mixx > Carte > Agents proches
- Plus de **6 000 agents** au Senegal et au Togo
- Les agents Mixx sont identifies par le logo violet Yas

### Agent Mixx frauduleux ?
1. Contacter le **3232** immediatement
2. Donner l'ID ou le nom de l'agent, le montant concerne, la date et l'heure
3. Mixx suspendra l'agent pendant l'investigation
4. Si fraude confirmee, remboursement integral sous **24 heures**
