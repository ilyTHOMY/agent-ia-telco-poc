# FAQ Orange Money Senegal — Support Client

## Frais et Tarifs (mis a jour 2025)

### Quels sont les frais de transfert Orange Money au Senegal ?
Orange Money Senegal applique les frais suivants (compte-a-compte, depuis l'application) :
- **Transfert compte a compte : 0,8% du montant envoye**
  - Ex : 80 FCFA pour 10 000 FCFA envoye
  - Ex : 800 FCFA pour 100 000 FCFA envoye
  - **Plafond des frais : 4 500 FCFA** quel que soit le montant
- **Depot (cash-in) chez agent : GRATUIT**
- **Retrait (cash-out) chez agent : GRATUIT**
- **Transfert avec code (sans compte beneficiaire) : 0,8% du montant**
- **Paiement de factures (SENELEC, SEN'EAU) : GRATUIT**

### Quels sont les frais de transfert international ?
Depuis le Senegal vers les pays de la sous-region : **1,5% du montant**

### Quelle est la limite mensuelle ?
- Profil verifie : **2 000 000 XOF par mois**

### Quelle est la limite de solde sur le compte ?
- Profil Classique verifie : maximum **2 000 000 XOF**

## Code USSD

### Comment acceder a Orange Money sans smartphone ?
Composez **#144#** depuis votre telephone (fonctionne sur tous les mobiles, meme sans internet).
Menu principal :
1. Envoyer de l'argent
2. Retirer de l'argent
3. Payer une facture
4. Consulter mon solde
5. Mon compte

### Comment envoyer de l'argent via USSD (#144#) ?
1. Composer **#144#**
2. Choisir "1. Envoyer de l'argent"
3. Entrer le numero du beneficiaire
4. Entrer le montant
5. Confirmer avec votre PIN a 4 chiffres

## Paiement de Factures

### Comment payer ma facture SENELEC ?
Via l'application Orange Money :
1. Menu > Payer une facture > SENELEC
2. Entrer votre numero de contrat SENELEC (visible sur votre facture)
3. Verifier le montant affiche
4. Confirmer avec votre PIN
Via USSD : composer **#144#** > "3. Payer une facture" > "SENELEC"
**Le paiement est gratuit et instantane.**

### Ma facture SENELEC est payee mais je suis toujours coupe ?
Delai de traitement normal entre Orange Money et SENELEC : **15 a 30 minutes maximum**.
Si apres 2 heures votre electricite n'est pas retablie :
1. Verifier que le paiement est bien marque "Succes" dans votre historique
2. Relever la reference du paiement (visible dans l'historique)
3. Contacter Orange Money au **888** (disponible 24h/24)
4. Contacter SENELEC directement avec votre reference de paiement

### Comment payer ma facture SEN'EAU ?
Meme procedure que pour SENELEC.
Votre numero de contrat SEN'EAU est visible sur votre facture d'eau.
Le paiement est pris en compte sous **30 minutes** chez SEN'EAU.

## Transactions

### Mon transfert n'est pas arrive, que faire ?
1. Verifier l'historique dans l'application (Menu > Historique)
2. Si statut "En attente" depuis plus de 30 minutes, appeler le **888**
3. Fournir : votre numero, le numero du beneficiaire, le montant et l'heure de la transaction
4. Un conseiller recherchera la transaction dans le systeme
Orange Money s'engage a resoudre les transferts perdus sous **24h**.

### J'ai envoye vers le mauvais numero, que faire ?
Appeler immediatement le **888** — plus la demande est rapide, plus les chances de recuperation sont elevees.
Si le beneficiaire est aussi client Orange Money et n'a pas retire, Orange Money peut tenter le retour.
Si le montant a ete retire, une mediation sera tentee.

## Securite

### Que faire en cas de fraude ou SIM swap ?
1. **Blocage immediat** : appeler le **888** et demander le blocage d'urgence de votre compte
2. Vous rendre dans une agence Orange Money avec votre CNI originale
3. Porter plainte a la Division Speciale de Cybersecurite (DSC) de la police senegalaise
Orange Money peut rembourser les pertes liees a un SIM swap prouve apres investigation interne.

### Orange Money vous demandera-t-il votre PIN par telephone ?
**Non, jamais.** Si quelqu'un vous appelle en pretendant etre Orange Money et vous demande votre PIN, raccrochez immediatement et appelez le **888** pour signaler la tentative de fraude.

## Reseau d'Agents

### Comment trouver un agent Orange Money ?
- Application Orange Money > Trouver un point de service
- Via USSD : **#144#** > "5. Mon compte" > "Agents proches"
- Plus de **100 000 agents** en zone UEMOA, dont de nombreux au Senegal

### L'agent a encaisse mon argent sans crediter mon compte ?
Procedure d'urgence :
1. Rester sur place si possible, demander un recu
2. Appeler immediatement le **888**
3. Orange Money suspendra le compte de l'agent pendant l'investigation
4. Si fraude confirmee, remboursement integral sous **48h**
