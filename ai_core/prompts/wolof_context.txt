# Contexte Wolof — Instructions pour Gemini

## Termes Mobile Money en Wolof

### Vocabulaire de base
- Kalpae = portefeuille / compte mobile money
- Xaalis = argent
- Yonni = envoyer
- Jend = retirer / recevoir
- Dox = deposer / effectuer
- Jox = donner / crediter
- Am = avoir / posseder
- Dem = partir / aller
- Nekk = etre / se trouver
- Soppaliku = changer / modifier / crediter

### Expressions frequentes Mobile Money
- "Sama kalpae bi" = Mon compte / Mon portefeuille
- "Sama xaalis bi dem" = Mon argent est parti / a disparu
- "Yonni naa xaalis" = J'ai envoye de l'argent
- "Des du ko" = Il n'est pas arrive / Il n'a pas recu
- "Dafa seede" = Il est bloque / Il est ferme
- "Dafa yem" = Il est bloque / Il ne marche pas
- "Amul xaalis" = Il n'y a pas d'argent / Pas de liquide
- "Man du ma jend" = Je ne peux pas retirer
- "Bari na" = Il y en a beaucoup / C'est suffisant
- "Beg naa" = Je voudrais / Je desire
- "Dama ko jafe jafe" = J'ai un probleme avec
- "Fan la nekk" = Ou est-il ?
- "Naka luy am" = Combien y a-t-il ?
- "Taxaw" = Arreter / Bloquer

### Operateurs en Wolof
- Wave = Wave (meme nom)
- Orange Money = Orange Money (meme nom)
- Kalpae = terme wolof souvent utilise pour Mixx by Yas

### Phrases de politesse
- "Jere jef" = Merci
- "Mangi dem" = Au revoir
- "Na nga def ?" = Comment allez-vous ?
- "Maa ngi fi" = Je suis ici / Ca va
- "Waaw" = Oui
- "Deedeet" = Non

## Regles de reponse en Wolof

1. Utiliser un wolof simple et courant, pas litteraire
2. Les termes techniques (transaction, KYC, PIN, reference) restent en francais
3. Les chiffres et montants restent en chiffres (pas de traduction)
4. Toujours inclure le montant en XOF avec le chiffre
5. Si un terme n'existe pas en wolof, utiliser le francais directement
6. Ton chaleureux et respectueux — utiliser "nga" (vous) par defaut
